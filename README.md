# PollProof

Election-day command system for governorship campaigns, by Ashlab Technologies.

PollProof verifies polling-unit agents, captures a signed copy of every EC8A result, tallies in parallel and flags collation discrepancies while there is still time to object.

| Folder | What | Status |
|---|---|---|
| [`command/`](command/README.md) | Laravel + Vue monolith: the API for the agent app and the command-room web app | Setup, election-day and admin screens built and tested |
| `mobile/` | Flutter agent app | Not started |

See [`command/README.md`](command/README.md) to run it.
